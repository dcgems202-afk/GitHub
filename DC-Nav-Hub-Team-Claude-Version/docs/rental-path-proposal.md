# Posting 16, Revision A — Find a Place to Rent (proposed question flow)

**NEW PROPOSED CONTENT — OWNER REVIEW REQUIRED**

This revises the proposed Posting 16. It is not recovered material. Recovered wording is marked **[RECOVERED]**; everything else is proposed.

## What changed from Posting 16

1. Step 2 now asks about the person's situation, so it matches the recovered button "Choose situation details."
2. Repeats removed: pets and assistance animals appear only in Step 2; human guidance appears in Step 1, and its comparison appears when it's selected.
3. Step 3 no longer asks people to sort resource types. It asks what would help most, and its button states what happens next.
4. Rent help, no stable place, safety at home, older adults, and veterans now have choices, so those verified records can be reached and the urgent-first rule works.
5. Pet and assistance animal are separate choices (record #5 note).
